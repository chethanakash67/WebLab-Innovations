# AigleOn Labs — Aigleon Library

The Aigleon Library is AigleOn Labs' public knowledge base of research, case studies, audits, benchmark comparisons, and guides — all done on current market conditions and real brands. It's kept up to date with real insights gathered from the market and from working businesses, so the research doesn't go stale.

Documents in the library are categorized by type: audits, reports, benchmark comparisons, guides, and case studies. Visitors can search and filter the library by keyword or document type on the Library page of the site, and open any document directly.

This library is separate from the Lab's own Q&A knowledge base — it's a downloadable resource archive rather than something the assistant reads from directly, but it's worth pointing visitors to it if they ask about research, case studies, or audits AigleOn Labs has published.
